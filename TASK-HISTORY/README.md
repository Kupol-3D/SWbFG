## Воспроизвести автоматическую проверку

Из корня, в окружении Python 3.14:

```sh
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tools -p 'test_*.py'
```

Для аудита без каких-либо вызовов Git задайте `SPACE_ARENA_NO_GIT=1`
(в PowerShell: `$env:SPACE_ARENA_NO_GIT='1'`). Hygiene-тест тогда проверяет
файлы рабочего дерева с учётом локальных ignore-правил, а не индекс Git.
Локальный аудит проведён на Linux/Python 3.11.2; целевая 3.14 указана в CI,
но наличие workflow само по себе не означает, что CI уже прошёл.
