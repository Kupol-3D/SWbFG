# Приём моделей и профилей полёта

Для каждого корабля:

- ID/фракция, автор/источник/лицензия и разрешение на изменение/раздачу.
  Не брать извлечённые игровые ресурсы с неизвестными правами.
- Исходная геометрия/текстуры; оригинал сохраняется неизменным с SHA256.
  Формат/экспорт согласовать, runtime первого этапа — `.ac` с XML-обёрткой.
  Поддержку формата проверить целевой сборкой FG/OSG.
- Единицы/размеры, нос/верх/центр, место глаз пилота, опоры/сопла/дула/
  внешние камеры. Проверить из кабины и снаружи.
- Атмосферные требования: масса/инерция, скорость/разгон, поддержка веса,
  ограничения манёвра/управление. Все допущения с единицами; данные лора
  не являются готовыми коэффициентами FDM.
- Игровые HP/щиты и анимации отдельно от аэродинамики; один расходуемый
  слот на конкретный тип за матч.

Приёмка: права/ресурсы → камера/геометрия → native FDM, если требуется →
старт/управление/полёт → правильная MP-модель на двух клиентах → боевой
lifecycle. Ошибка solver, fallback MP-модель или камера внутри геометрии
блокируют приёмку, даже если структурные тесты зелёные.

Статический тест не доказывает устойчивость, визуальное качество или FPS.
