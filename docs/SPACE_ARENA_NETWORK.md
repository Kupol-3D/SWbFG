# Сеть: диагностика и игровой маршрут

Целевая архитектура — `SPACE_ARENA_GATEWAY.md`: TLS gateway перед приватным
FGMS. Direct UDP в `tools/launch.py` — локальная диагностика, не публичный
способ допуска в матч.

- FG MP использует UDP; сервер задаётся IPv4/DNS. `0.0.0.0` — возможный bind,
  не адрес назначения. Callsign не credential.
- `server/space/compose.local.json` публикует только `127.0.0.1:5500`.
  Публикация ещё не доказывает обратный поток и правильность NAT.
- `ssh -L/-R` пробрасывает TCP, не превращая UDP FGMS в авторизованный канал.
- FGMS не шифрует/не аутентифицирует обычный MP и не судит HP/счёт.
  TLS-доступ и авторитет правил — разные слои.
- Приёмка: два настоящих клиента, разные callsign/receive-port, движение
  в обе стороны и reconnect. Echo/dry-run/структурные тесты этого не доказывают.
