## Camera mapping

Integration stores asset coordinates (X right, Y forward, Z up). The builder
maps an asset point to the FG model point `(-Y, X, Z)` and view offsets
`(X, Z, -Y)` (right, up, aft). Internal cameras use 75 deg horizontal FOV and
0.04 m near plane. Royal Guard and Boarding use `PilotCamera`; M1 uses
`RemoteOperatorCamera` with `NON_CANON_Gameplay` interior.
