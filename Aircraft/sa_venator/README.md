# sa_venator — носитель с внутренним боковым ангаром

Канонический пакет разрушителя находится в **Aircraft**, а не в scenery:
это отдельный корабельный ресурс для последующего AI/сетевого движения.
Готовые сетки поставляются с репозиторием. Blender, исходный стартер-пак
и генерация `.ac` для запуска не требуются.

## Состав

- `Models/carrier_lod0.ac`, `carrier_lod1.ac`, `carrier_lod2.ac` — три цельных
  LOD корпуса и интерьера: 371341 / 79857 / 47825 треугольников.
- `Models/carrier.xml` — единственная модельная XML-обёртка с range-LOD.
- `Models/layout.json` — размеры, оси, стартовые кандидаты и проверки проёма.
- `sa_venator-set.xml` — FG aircraft entry point для осмотра.
- `Sources/BUILD_MANIFEST.json` — SHA-256 всех файлов пакета, кроме себя.
- `LICENSE_ATTRIBUTION.md` — авторство, хэши исходников и статус условий.

Проектная игровая длина — 3000 м, не каноническая длина Venator. Ангар внутри
борта, днище сохранено, наружного короба и подвешенных декоративных TIE нет.
Две створки смоделированы в статическом открытом положении. Исходные UV-атласы
ещё не запечены; текущая поставка использует цвета материалов.

## Осмотр самого корабля

Из корня репозитория, с установленными FlightGear/FGData:

```sh
fgfs --launcher=0 --no-default-config=1 \
  --fg-aircraft="$PWD/Aircraft" --aircraft=sa_venator \
  --in-air --lon=-122.455 --lat=37.415 --altitude=5000 \
  --heading=250 --vc=0 --timeofday=noon --enable-terrasync
```

`v` переключает обзор ангара/внешний вид. **Это не готовое управление кораблём:**
`flight-model=null`, бэкенд движения/FDM пока не подключён. Не добавляйте при
этом статическую сцену с ещё одним экземпляром носителя в той же позиции.

## Размещение в арене

Готовая `scenery/space_arena_carrier` хранит только размещение и XML-ссылку
`Aircraft/sa_venator/Models/carrier.xml`, без копии мешей. Для её осмотра
нужны `--fg-aircraft="$PWD/Aircraft"` и соответствующий `--fg-scenery`;
команда — в README сцены. Пока это **статическое preview-размещение**.
Следующий бэкенд AI/сети должен двигать экземпляр этого же Aircraft-пакета,
а не отдельную копию сцены.

## Проверено и не проверено

Геометрически проверены пять объёмов вылета 14×14×9 м и сохранность днища.
Модель наблюдалась на FG 2024.1.4, включая загрузку из этого Aircraft-пакета
через сцену-ссылку и `FG_AIRCRAFT`; целевая версия проекта — 2024.1.7.
Наличие ассета не подтверждает AI-движение, FDM, поддержку палубой, столкновения,
игровой спавн, сеть, runtime-переключение LOD или производительность на GPU.
Новые камеры aircraft entry point требуют отдельной визуальной приёмки.
